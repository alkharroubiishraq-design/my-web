# مراقب الحصة الذكي 🎥

تطبيق ويب (بدون سيرفر) يسجّل حصة صفية (كاميرا + مايك، مع إمكانية مشاركة شاشة
اللوح الإلكتروني بالتوازي) ويحلّلها بالذكاء الاصطناعي (Claude من Anthropic)
ليعطي المعلمة تقرير أداء منظّم (نقاط قوة/ضعف/توصيات) قابل للطباعة أو الحفظ
كـ PDF أو المشاركة عبر البريد/واتساب.

## الملفات

- `index.html` — النسخة الجاهزة للنشر مباشرة على GitHub Pages (فيها React
  و Babel من CDN، تعمل بدون أي خطوة بناء/Build).
- `classroom-observer.jsx` — نفس الكود كمكوّن React منفصل (نسخة مصدر/مرجع
  لمن يريد دمجه داخل مشروع React له خطوة بناء).

## المزايا

- تسجيل مباشر: كاميرا + مايك (`getUserMedia`) مع مشاركة شاشة اختيارية
  (`getDisplayMedia`) لتسجيل اللوح الإلكتروني بالتوازي.
- التقاط لقطات كل ٢٠ ثانية من الكاميرا واللوح (حتى ٥ لقطات لكل مصدر).
- تفريغ صوتي فوري بالعربي عبر Web Speech API (يعمل على متصفح Chrome فقط).
- خيار رفع فيديو حصة مسجّلة مسبقًا بدل التسجيل المباشر.
- تحليل عبر Claude API يُخرج تقرير JSON منظم (نقاط قوة، نقاط ضعف، توصيات).
- تقرير نهائي بتصميم "ورقة تقرير" قابل للطباعة/حفظ PDF.
- إرسال التقرير عبر رابط `mailto:` أو `wa.me` — يفتح تطبيق المستخدمة وهي
  تضغط إرسال بنفسها (لا يوجد إرسال تلقائي حقيقي لأسباب أمان، ولا تُخزَّن أي
  مفاتيح API في الكود أو على أي خادم).

## الاستخدام

1. افتح الصفحة المنشورة (أو `index.html` محليًا في المتصفح).
2. أدخلي مفتاح Anthropic API الخاص بك (من console.anthropic.com ← Settings
   ← API Keys) — كل استخدام له تكلفة بسيطة على حسابك الخاص بـ Anthropic.
3. ابدئي تسجيل الحصة (أو ارفعي فيديو مسجّل مسبقًا)، ثم اضغطي "تحليل" للحصول
   على التقرير.

## ملاحظة تقنية

هذا نموذج أولي (Prototype) يعمل بالكامل من المتصفح دون أي خادم خلفي، لذا
مفتاح API والصور/اللقطات تُرسَل مباشرة من متصفحك إلى Anthropic فقط. لا
تستخدمي الصفحة على جهاز/متصفح مشترك مع أشخاص لا تثقين بهم لأن المفتاح قد
يُحفظ محليًا أثناء الجلسة.
