# تصحيح 📝 — مساعدك الذكي لتصحيح أوراق الطلاب

موقع تعليمي بسيط (بدون سيرفر) يساعد المعلم على تصحيح الامتحانات الورقية:
تصوّر ورقة الأسئلة والإجابة النموذجية، ثم تصوّر ورقة كل طالب، والموقع يستخدم
الذكاء الاصطناعي (Claude من Anthropic) لتصحيح كل ورقة ومقارنتها بالإجابة
النموذجية، وإعطاء علامة وملاحظات لكل سؤال.

## كيف يعمل

- الموقع بالكامل صفحات HTML/CSS/JS ثابتة — لا يوجد أي سيرفر خلفي.
- كل بياناتك (الامتحانات، الطلاب، الصور، النتائج) تُحفظ **محلياً في متصفحك فقط**
  عبر `localStorage`.
- عند الضغط على "تصحيح"، يرسل المتصفح الصور مباشرة إلى واجهة برمجة تطبيقات
  Anthropic (Claude API) باستخدام مفتاح API الخاص بك، ويستقبل النتيجة مباشرة.

## البدء

1. افتح `index.html` في المتصفح (أو انشر المجلد على أي استضافة ثابتة مثل
   GitHub Pages).
2. اضغط على أيقونة الإعدادات ⚙️ وأدخل مفتاح Anthropic API الخاص بك (يمكن
   الحصول عليه من console.anthropic.com ← Settings ← API Keys) واختر النموذج
   المناسب.
3. أنشئ امتحاناً جديداً، وارفع صورة الإجابة النموذجية (وصورة ورقة الأسئلة
   اختيارياً).
4. أضف الطلاب باسم كل طالب وصورة ورقة إجابته، ثم اضغط "تصحيح" لكل طالب أو
   "تصحيح الكل" لتصحيح الجميع دفعة واحدة.
5. راجع تفاصيل التصحيح لكل طالب، وعدّل العلامة يدوياً إن لزم.
6. صدّر النتائج كملف Excel أو اطبعها/احفظها كـ PDF.

## ملاحظات هامة

- **الخصوصية**: مفتاح API والصور تُرسَل مباشرة من متصفحك إلى Anthropic فقط،
  ولا تمر عبر أي خادم وسيط. لا تستخدم الموقع على جهاز/متصفح مشترك مع أشخاص
  لا تثق بهم لأن المفتاح يُحفظ محلياً.
- **النسخ الاحتياطي**: بما أن البيانات محفوظة في المتصفح فقط، يُنصح بتصدير
  نسخة احتياطية دورياً من الإعدادات ⚙️.
- **مساحة التخزين**: صور كثيرة قد تملأ مساحة التخزين المخصصة للمتصفح. يمكن
  إلغاء تفعيل خيار "الاحتفاظ بصور الطلاب بعد التصحيح" لتوفير المساحة.
